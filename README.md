Title: Employee-Management-System: Using OOP to Model Roles and Hierarchies
Descrption: A model employee management system that utilizes classes and hierarchies to simulate organizational structures and employee data.
Technologies Used: Javascript
How To Run The Project: Search about:blank on your search engine and paste the system into the console. OR Run the Javascript through a console.
What you Learned From Building It: I learned a lot about how you can use classes to create a organized structure through javascript. I learned how to organize employees into the classes that can be used for future business applications.
